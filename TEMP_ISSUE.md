# Mobile Layout Broken on Right Side

## Device Information
- **Device:** iPhone 11 Pro
- **Browsers:** Safari, Arc Browser (both produce same issue)

## Issue Description
Mobile web function is normal, except the layout is somehow broken on the right side. There is a misaligned element that creates blank space on the right side of the screen.

## Current Behavior
- Misaligned elements on mobile viewport
- Blank/wasted space appearing on the right side
- Affects both Safari and Arc Browser on iPhone 11 Pro

## Expected Behavior
- Layout should be fully responsive and properly aligned on mobile devices
- No blank space or overflow on the right side
- All elements should fit within the viewport

## Steps to Reproduce
1. Open the application on iPhone 11 Pro
2. Open using Safari or Arc Browser
3. Observe the right side of the screen
4. Notice misaligned elements and blank space
